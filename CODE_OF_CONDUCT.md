# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful and harassment-free for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept responsibility for impact.
- Keep technical discussions focused on the work.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Public or private abuse of project participants.
- Publishing private information without permission.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation when behavior violates this code of conduct.
