# Security Policy

## Supported Versions

Security fixes are provided for the latest released major version.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by emailing the maintainer listed in the NuGet package metadata.

Include:

- Affected version or commit.
- A minimal reproduction or proof of concept.
- Expected and actual behavior.
- Any known impact or mitigation.

Do not publish exploit details until a fix or mitigation has been released.
